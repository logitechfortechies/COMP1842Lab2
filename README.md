The primary objective of this week's lab was to introduce interactivity and reactive rendering logic into the application. I implemented the v-for directive to iterate through data arrays, automatically generating list items for product details. Additionally, I utilized the v-if and v-else directives to conditionally render UI elements, such as dynamically displaying whether a product is "In Stock" or "Out of Stock" based on the exact inventory count. To handle user interactions, I integrated event listeners using the v-on directive (shorthand @), specifically using @click to increment a shopping cart counter and @mouseover to update the main product image instantly.

Understanding the underlying mechanics of conditional rendering was a key focus this week. Unlike simply toggling CSS visibility classes (e.g., display: none) with vanilla JavaScript, Vue’s v-if directive physically inserts or destroys the HTML elements within the DOM based on the evaluated truthiness of the expression. This makes the application highly memory-efficient, as it does not keep hidden elements loaded in the background. Combining this efficiency with Vue's automated event handling significantly streamlines the logic required to build highly responsive, state-driven user interfaces.
